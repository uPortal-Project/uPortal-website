# uPortal Contributor Info and Onboarding

Contributing to uPortal looks like contributing to most open-source projects: open a pull request, respond to review, iterate, and ship. There is no contributor license agreement to sign and no formal application process to file. The bar is your work and your engagement with the community.

## First steps

1. **Join the mailing lists.** Subscribe to [`uportal-user`](https://groups.google.com/u/3/a/apereo.org/g/uportal-user) and [`uportal-dev`](https://groups.google.com/u/3/a/apereo.org/g/uportal-dev). Lurk for a bit if you'd like — you'll get a feel for what's actively being discussed.
2. **Skim the [Code of Conduct](code-of-conduct.html).** It's brief and reflects the [Apereo Welcoming Policy](https://www.apereo.org/content/apereo-welcoming-policy).
3. **Find the repo that's relevant to your contribution.** The full inventory is at [Repositories](../support/repositories.html). Most active development happens in [uPortal-Project](https://github.com/uPortal-Project).
4. **Build it locally.** The [Deployment Guide](../support/deployment-guide.html) and [Developer Guide](../support/developer-guide.html) cover bootstrapping a working portal.
5. **Open a pull request.** Small, focused PRs are easier to review than large ones. Reference an issue if there is one.

## What contributions are welcome

Anything that improves uPortal:

- Bug fixes — especially with a reproducing test
- Documentation — both this site and the [uPortal manual](https://github.com/uPortal-Project/uportal-project.github.io)
- New features and refactors — please open an issue or post to `uportal-dev` first for non-trivial changes, so the design conversation happens before the code
- New portlets and web components — if it's broadly useful, consider proposing it for the [uPortal-Contrib](https://github.com/uPortal-Contrib) organization
- Triage and review on existing PRs and issues
- Testing on real deployments and reporting back

## Becoming a committer

After sustained contribution, an existing committer may nominate you on `uportal-dev`. The vote is informal and happens on the list. Once approved, you'll be added to the `uPortal Committers` team across the three GitHub organizations and gain merge and release rights.

The full committer onboarding checklist — Sonatype credentials, PGP key setup, voting norms — is maintained alongside the manual at [committer-onboarding.md](https://github.com/uPortal-Project/uportal-project.github.io/blob/master/manuals/en/uportal5-manual/developer/committer-onboarding.md).

## Where to get help

- Stuck on a build? Ask on `uportal-user`.
- Design question on something you're working on? `uportal-dev`.
- Sensitive topic (security, governance)? `uportal-steering-committee@apereo.org`.
