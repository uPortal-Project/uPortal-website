# uPortal Committers

Committers are the developers who have merge and release privileges across the uPortal ecosystem. They review pull requests, cut releases on Maven Central and npm, and vote on project-level decisions. The role is earned through sustained contribution — see [Contributor Info and Onboarding](contributor-info.html) for the path from contributor to committer.

Committers are organized into a `uPortal Committers` team across three GitHub organizations:

- [uPortal-Project](https://github.com/orgs/uPortal-Project) — the core project and actively maintained portlets and tools
- [uPortal-Contrib](https://github.com/orgs/uPortal-Contrib) — community-maintained portlets and integrations
- [uPortal-attic](https://github.com/orgs/uPortal-attic) — archived projects kept for historical reference

The current committer roster is visible on the team pages above. For the subset of committers who currently sit on the Steering Committee, see [Governance](../about/governance.html).

## What committers do

Committers have three responsibilities beyond regular contribution:

1. **Vote on project decisions** — calls for vote happen on the `uportal-dev` [mailing list](mailing-lists.html)
2. **Review and merge pull requests** — quality gate for the ecosystem; in general a PR is reviewed and merged by committers *other* than the author, but one committer doesn't need to do all the steps
3. **Cut releases** — uPortal core and portlets ship on Maven Central, JavaScript packages on npm (with WebJar mirrors on Maven Central)

The release process — including Sonatype credentials, signing keys, and the post-release validation steps — is documented in [the uPortal manual](https://github.com/uPortal-Project/uportal-project.github.io/blob/master/manuals/en/uportal5-manual/developer/maven-release-process.md).

## How committers are added

Active contributors are nominated by an existing committer, discussed on the `uportal-dev` list, and added by a committer vote. New committers are added to the `uPortal Committers` team in each of the three GitHub organizations.

If you'd like to become a committer, the path starts with contributing: open pull requests, review others' PRs, and show up on the mailing lists. See [Contributor Info and Onboarding](contributor-info.html) for the practical onboarding checklist.
