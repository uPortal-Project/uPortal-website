# uPortal Communications

Most uPortal conversation happens on two public mailing lists. They're hosted by the Apereo Foundation at `groups.google.com` (the Google-Groups-flavored Apereo lists), and the archives are open to anyone who wants to search them.

## Mailing lists

### uportal-user

- **Address:** `uportal-user@apereo.org`
- **Archive and signup:** [groups.google.com/a/apereo.org/g/uportal-user](https://groups.google.com/u/3/a/apereo.org/g/uportal-user)
- **What it's for:** using and deploying uPortal — installation help, configuration questions, integrating portlets and web components

### uportal-dev

- **Address:** `uportal-dev@apereo.org`
- **Archive and signup:** [groups.google.com/a/apereo.org/g/uportal-dev](https://groups.google.com/u/3/a/apereo.org/g/uportal-dev)
- **What it's for:** development of uPortal and uPortal-related projects — design discussions, release announcements, formal votes by committers

If you're not sure which list to use, `uportal-user` is the safe default. Cross-posting between the two is fine when a topic genuinely spans both.

## Other channels

- **GitHub** — open issues and pull requests on any repository in the [uPortal-Project organization](https://github.com/uPortal-Project)
- **Twitter / X** — [@uPortal](https://twitter.com/uPortal)
- **Open Apereo conference** — annual in-person gathering where the community discusses roadmap, releases, and shared work. See [apereo.org/events](https://www.apereo.org/events) for the current year's dates.
- **uPortal Steering Committee** — for governance or security questions: `uportal-steering-committee@apereo.org`

## Reporting security issues

Please **do not** disclose security vulnerabilities on the public mailing lists. Email `uportal-steering-committee@apereo.org` directly. Supporting Subscribers receive advance notice of security patches as part of their subscription benefits — see [Paid Support](../support/paid-support.html).
